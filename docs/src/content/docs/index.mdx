## The 60-second pitch

<div class="pitch-columns">
  <article>
    <h3>Branches, not linear chats.</h3>
    <p>Fork any message, explore, and merge the useful branch back into main with a reviewed summary. Sibling branches never leak into each other's context.</p>
  </article>
  <article>
    <h3>Every prompt is inspectable.</h3>
    <p>The <code>ContextPacket</code> shows exactly which messages, merges, and wiki pages were included, plus the rendered prompt preview and system preamble. No hidden retrieval magic.</p>
  </article>
  <article>
    <h3>Merge is not distill.</h3>
    <p>Merges land what a branch should know now. Distill turns transcripts into durable wiki pages that future conversations can retrieve. Both stay user-triggered.</p>
  </article>
</div>

## A minimal embed

<Tabs>
  <TabItem label="Node">
```ts
import { Bonsai } from '@bonsai/core';
import { createPostgresStorage } from '@bonsai/storage-postgres';
import { OpenAIProvider } from '@bonsai/provider-openai';
import { FsWikiStore } from '@bonsai/wiki-fs';
import { Pool } from 'pg';

const pool = new Pool({ connectionString: process.env.DATABASE_URL });
const storage = createPostgresStorage({ pool });

const bonsai = new Bonsai({
  storage,
  provider: new OpenAIProvider({ apiKey: process.env.OPENAI_API_KEY! }),
  wiki: new FsWikiStore({ root: './wiki' }),
});

const project = await bonsai.createProject({ name: 'demo' });
// createProject seeds exactly one branch, named "main".
const [main] = await storage.branches.findByProjectId(project.id);

// Inspect the exact context before you spend a token.
const packet = await bonsai.assembleContext(main.id);
// packet.messages / packet.includedWikiPageIds / packet.renderedPromptPreview
// are all inspectable — see the ContextPacket concept page.

for await (const chunk of bonsai.chat(main.id, 'What can you tell me about branchable conversations?')) {
  process.stdout.write(chunk.content);
}
```

```ts
// app/api/chat/route.ts
import { handleChat, parseChat } from '@bonsai/server';
import { getBonsaiDeps } from '@/lib/bonsai';

export async function POST(req: Request) {
  const deps = await getBonsaiDeps(); // { bonsai, retriever? }
  const chatReq = parseChat(await req.json());
  const stream = handleChat(deps, chatReq);

  const body = new ReadableStream({
    async start(controller) {
      for await (const chunk of stream) {
        controller.enqueue(new TextEncoder().encode(chunk.content));
        if (chunk.done) break;
      }
      controller.close();
    },
  });
  return new Response(body);
}
```

## Not the app, the primitives

`@bonsai/*` ships the domain (tree, branch, merge, distill, ContextPacket) and adapter contracts (Storage, LLMProvider, WikiStore, Retriever). It does not ship a UI. Build your own product surface — a chat app, an editor, a research assistant — on top.

<div class="honesty-band">
  <p><strong>What's stable:</strong> the core interfaces, the Postgres storage, the OpenAI-compatible provider, the on-disk wiki store, and the FTS retriever.</p>
  <p><strong>What's still <code>0.x</code>:</strong> embeddings / vector retrieval, multi-tenant storage, and the HTTP server layer. See <a href="/contributing/rfc-process/">the RFC process</a> if you need to shape these.</p>
</div>
