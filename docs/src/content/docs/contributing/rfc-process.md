---
title: RFC Process
description: How to propose a change to the core interfaces.
---

Any change that touches a public interface in `@bonsai/core` (Storage, LLMProvider, WikiStore, Retriever, ContextPacket shape) requires an RFC.

> **Stub.** Process doc tracked in the [issue tracker](https://github.com/Joaoha/Bonsai/issues). Intended shape: open an issue with the `rfc` label, propose the shape and the migration story, wait for TL sign-off before opening the implementation PR.
