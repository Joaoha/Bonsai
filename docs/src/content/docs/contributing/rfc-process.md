title: RFC Process
description: How to propose a change to the core interfaces.
---

Any change that touches a public interface in `@bonsai/core` (Storage, LLMProvider, WikiStore, Retriever, ContextPacket shape) requires an RFC.

> **Stub.** Process doc tracked under [BONA-238](/BONA/issues/BONA-238). Intended shape: open an issue with the `rfc` label, propose the shape and the migration story, wait for TL sign-off before opening the implementation PR.
