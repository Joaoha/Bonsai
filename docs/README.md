# @bonsai/docs

Public documentation site for the `@bonsai/*` packages. Built with [Astro](https://astro.build/) + [Starlight](https://starlight.astro.build/); API Reference is auto-generated from source via [TypeDoc](https://typedoc.org/) and [starlight-typedoc](https://starlight-typedoc.vercel.app/).

Information architecture is defined in [BONA-222](/BONA/issues/BONA-222#document-ia). This package renders that IA — do not re-open IA decisions here without escalating to TL.

## Commands

Run from the repo root:

```
pnpm docs:dev     # local dev server, hot reload
pnpm docs:build   # produce static site under docs/dist
pnpm docs:preview # preview a built site locally
```

Or scoped:

```
pnpm --filter @bonsai/docs dev
pnpm --filter @bonsai/docs build
```

## Structure

```
docs/
  astro.config.mjs        # Starlight config: nav, integrations, TypeDoc plugin wiring
  src/
    content/docs/         # Prose pages (MDX + Markdown)
      index.mdx           # Landing page (IA §3 copy skeleton)
      quickstart.mdx      # 5-minute end-to-end walkthrough (mirrors examples/minimal-node)
      concepts/           # Tree Model, ContextPacket, Merge, Distill, Wiki, Retrieval
      recipes/            # Embed in Next.js, Custom Provider/Storage/Retriever
      contributing/       # Setup, Testing, Changesets, RFC Process
      examples.md
    content/docs/api/     # AUTO-GENERATED by TypeDoc; do not edit by hand
    assets/               # Logos, hero art, mark
    styles/custom.css     # Small brand overrides on top of Starlight defaults
  diagrams/               # SVG source + alt-text sidecars (per IA §5)
  public/                 # Static assets served as-is
```

## API Reference build

Every `@bonsai/*` public package has an entry in `astro.config.mjs` under `plugins:`. On `astro build`, `starlight-typedoc` runs TypeDoc against each package's `src/index.ts` and writes Markdown into `src/content/docs/api/<pkg>/`. That directory is `.gitignore`d — API pages are always regenerated from source.

Adding a new package to the API reference:

1. Add a `createStarlightTypeDocPlugin()` invocation at the top of `astro.config.mjs`.
2. Register it in the `plugins` array with `entryPoints`, `tsconfig`, `output: 'api/<pkg>'`.
3. Add the sidebar handle under the `API Reference` group.

## Diagrams

Diagrams live under `docs/diagrams/`. Each `<name>.svg` has a sibling `<name>.md` with alt-text (accessibility + LLM crawlability). Fidelity levels per IA §5.
